# Extension source index

TypeScript source tree and static assets for the GNOME Shell extension. This is
the source of truth; `../extension/` is generated by `npm run build`.

## Directories

- [`plugins/`](plugins/index.md) — built-in panel widgets, one directory per
  widget.
- `schemas/` — GSettings schema copied into generated extension and compiled by
  `./gwp install`.

## Core modules

- `ambient.d.ts` — ambient GJS/GNOME Shell type declarations for the whole
  TypeScript build (not emitted; `.ts` files are never copied to `extension/`).

- `extension.ts` — GNOME Shell extension entrypoint and floating panel actor.
- `prefs.ts` — preferences UI to add, remove, reorder, enable and configure
  widgets; see [`../docs/implementation/preferences.md`](../docs/implementation/preferences.md).
- `pluginManager.ts` — reads widget config, instantiates plugin actors and, on a
  live reload, keeps the ones the change did not touch
  (`updateConfiguredPlugins`).
- `mainPanel.ts` — `MainPanelController`: hides/auto-hides the GNOME top bar
  (`panelBox`) per the `main-panel` GSettings enum; a built-in replacement for
  the "Hide Top Bar" extension (`@tag:main-panel`).
- `configStore.ts` — reads/writes the `widgets` GSettings key (synchronous
  `loadWidgetConfig`; the one-time legacy `widgets.json` migration is the
  separate async `migrateLegacyConfigIfNeeded`, run from `enable()`); delegates
  parsing to `widgetConfig.ts`.
- `widgetConfig.ts` — gi-free parse/validate/serialize of the config document
  stored in the `widgets` key, plus `widgetInstanceKey` (the signature the panel
  reuses widget actors by); unit tested in [`../tests/index.md`](../tests/index.md).
- `aiCollector.ts` — the AI activity collector the extension owns: one localhost
  server for Claude's hooks, the Codex/Gemini helper processes, and the
  providers/prompts/sessions they feed. Runs on the `ai-collector` setting, not
  on which widgets are in the panel (`@tag:ai-collector`; see
  [`../docs/implementation/ai-collector.md`](../docs/implementation/ai-collector.md)).
- `contracts.ts` — typed contracts shared by host, registry and preferences.
- `tooltipTemplate.ts` — shared `renderTemplate` for user-editable Pango-markup
  hover tooltips; no `gi://` import, so it loads in both the Shell and the
  preferences process (`@tag:ui`).
- `colorUtils.ts` — gi-free colour/numeric helpers (`hexToRgb`, `toNumber`,
  `nowSeconds`) shared by the graph widgets (unit tested in
  [`../tests/index.md`](../tests/index.md)).
- `sessionInhibitor.ts` — shared `org.gnome.SessionManager` inhibitor access:
  `SessionInhibitor` (hold one, release it, survive a reply that lands after
  its owner is gone) and `queryInhibited()` (is anything else holding one?).
  Used by the caffeine widget and by the break timer's pause
  (`@tag:session-inhibitor`).
- `prefsDuration.ts` — shared settings row for a duration: the value written as
  `30 s` / `45 min` / `1:30` and `±` buttons whose step follows the value
  (`@tag:prefs-duration`).
- `duration.ts` — gi-free `formatDuration` (`M:SS`, `H:MM:SS` past an hour) so
  every countdown in the panel reads the same; no `gi://` import, so it loads in
  both processes (`@tag:ui`).
- `panelRotation.ts` — gi-free geometry shared by every Cairo widget in the
  panel: the drawing box for a surface (taken from the **surface**, never from
  the size the widget asked for) and the transform that turns it for a vertical
  strip; unit tested in [`../tests/index.md`](../tests/index.md) (`@tag:ui`).
- `panelText.ts` — `PanelText`, panel text drawn with PangoCairo so it can turn
  90° in a vertical strip instead of being ellipsized to `…`; used by the clock
  and by the cloned quick-settings labels (`@tag:ui`).
- `tooltip.ts` — shared hover-tooltip positioning (`positionTooltip`) and
  show/hide animation (`animateTooltipVisibility`) used by the graph widgets.
- `prefsColor.ts` — shared preferences colour helpers (`hexToRgba`,
  `rgbaToHex`, unified `colorButton` factory) used by the widget prefs pages.
- `prefsAiCollector.ts` — the "AI collector" preferences group (master switch,
  per-agent switches, hook port). A module rather than a method on the
  preferences class so the settings smoke test can build it
  (`@tag:ai-collector`).
- `prefsTemplate.ts` — shared preferences tooltip-template editor
  (`addTemplateEditor`) used by the graph-widget prefs pages.
- `controlButton.ts` — panel handle, menu (build-identity header, Settings…,
  Release notes, extensions.gnome.org, Report a bug) and movement controls.
- `version.ts` — gi-free release-channel (`alpha`) badge constant and
  version-label formatting shared by the menu, About group and bug reports; unit
  tested in [`../tests/index.md`](../tests/index.md) (`@tag:versioning`; see
  [`../docs/process/release.md`](../docs/process/release.md)).
- `buildStamp.ts` — gi-free contract, parser and `commit[-dirty]` formatting for
  the `build-stamp.json` `./gwp build` writes into the tree; shared by the handle
  menu and the version-status widget (`@tag:build-stamp`; unit tested in
  [`../tests/index.md`](../tests/index.md)).
- `systemInfo.ts` — shared helper: reports the extension version
  (`versionName`/`versionDisplay`) and which build is running
  (`readBuildStamp`/`buildIdDisplay`), builds the current-version release-notes URL
  (`releaseNotesUrl`), changelog URL and the extensions.gnome.org store URL
  (`egoUrl`), collects a best-effort system report, builds prefilled GitHub
  issue-form URLs (bug/feature/widget request) and opens URLs; runs in both the
  Shell and preferences process (`@tag:mechanism`).
- `indicatorsDrawer.ts` — reusable GNOME indicator clone drawer.
- `utils.ts` — monitor/panel helper functions.

The plugin metadata registry used by preferences is
[`plugins/registry.ts`](plugins/registry.ts).

See [`../docs/implementation/object-model.md`](../docs/implementation/object-model.md) for runtime objects.
