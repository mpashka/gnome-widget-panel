# Roadmap

What is planned or considered but not built yet. Anything here is a candidate,
not a promise; once it ships it moves into
[`../specification/index.md`](../specification/index.md) (user-visible behaviour) and
[`../implementation/index.md`](../implementation/index.md) (how it works).

## Files

- [`backlog.md`](backlog.md) — the maintained backlog: incremental TypeScript
  contract typing, panel features and requested widgets/settings. Update it when
  a contract is completed, split or newly discovered.
- [`widget-ideas.md`](widget-ideas.md) — reference: XFCE-inspired candidate
  widgets and a prioritized shortlist for what to add next (`@tag:reference`).
- [`ai-management.md`](ai-management.md) — concept for AI-assisted panel
  management (describe an indicator, let an orchestrator find or prepare it)
  with its safety constraints.
