# "Keep the ones I use to hand"

`@tag:use-case` `@tag:widget-gnome-menu`

Back to [launch](index.md) · [use cases](../index.md).

**Goal.** I have the applications menu open, looking at a program I start every
day, and I want it one hover away next time.

## Steps

1. [S3](../steps.md#s3) on the **Applications** widget; find the application —
   by [browsing](start-application.md) or by [typing](find-application.md).
2. **Right-click that row** ([S6](../steps.md#s6)) → **Add to Favorites**.
3. The **Favorites** category updates in the menu that is still open — you can
   check it without reopening anything.

**Cost.** Two clicks from the open menu, and no dialog: adding a favorite is
free and undone the same way.

## Variants

- **Take it back out.** Right-click it again → **Remove from Favorites**. It is
  the *same* item, showing whichever action applies now — never both, one of
  them greyed.
- **Where is the list?** It is GNOME's own favorites list, so the panel's
  Favorites category and the Dash in the Overview show the same applications.
- **Somewhere to put files and folders instead.** Applications go to Favorites;
  folders and bookmarks are [Places](open-place.md).

## Result

The application sits in the **Favorites** category from now on, [as
long](../steps.md#r2) as it is a favorite — and the menu proved it before you
closed it.
