# "Grab a picture of this"

`@tag:use-case` `@tag:widget-printscreen`

Back to [launch](index.md) · [use cases](../index.md).

**Goal.** Take a screenshot or a screen recording — on a keyboard where PrtSc is
awkward, missing, or already taken by something else.

## Also assumes

The **Screenshot** widget on the panel ([add it](../configure/add-widget.md)).

## Steps

1. **Click the button.** GNOME's interactive screenshot overlay opens — the same
   one the PrtSc key shows: area, window or whole screen, plus screen recording.
2. Continue in that overlay as usual.

**Cost.** One click instead of a key you do not have.

## Variants

- **A screenshot for a bug report.** That is exactly what a report needs — see
  [`../support/report-bug.md`](../support/report-bug.md).
- **Recording a screencast.** Same overlay, its recording tab; the panel is
  visible in the result unless you
  [collapse it](../setup/collapse-panel.md) first.

## Result

Whatever GNOME's screenshot UI produces, saved where it always saves it. The
widget only opens the overlay — it does not capture anything itself.
