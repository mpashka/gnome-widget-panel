# "Start one of the applications I use every day"

`@tag:use-case` `@tag:widget-gnome-menu`

Back to [launch](index.md) · [use cases](../index.md).

**Goal.** I start this application repeatedly and already put it in GNOME
Favorites; I want the shortest pointer route to it from the desktop.

## Steps

1. [S3](../steps.md#s3) on the **Applications** widget. The menu opens on
   **Favorites** when that category exists.
2. Click the application.

**Cost.** Two clicks from the desktop; no category hover and no typing.

**Frequency.** Potentially many times per day for a favorite, but this is a
scenario estimate rather than measured telemetry.

## Variants

- **It is not a favorite yet.** Add it where it already appears:
  [`favorites.md`](favorites.md).
- **I know its name and the favorite list is long.** Type immediately and press
  `Enter`: [`find-application.md`](find-application.md).
- **I prefer GNOME's Overview.** Use its normal keyboard route, or add a
  [Gnome Action](open-overview.md) button.

## Result

The application starts and the menu closes. Favorites are GNOME's own list, so
the same membership appears in the Overview.
